# posts/

- `drafts/` — Claude writes here. Each file has `status: draft`. You edit in place, then set `status: approved` or `rejected`.
- `published/` — after you post it on LinkedIn, move the file here, set `published:` and `url:` in the frontmatter. This is your archive and your analytics input.

A post file follows `templates/post.md`. The "Notes for the owner" section tells you which facts came from `cv/` and which were inferred. Check the inferred ones every time.
